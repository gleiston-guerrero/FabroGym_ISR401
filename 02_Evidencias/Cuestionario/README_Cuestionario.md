No se declara una sexta fotografía porque el conjunto documental verificable del proyecto está constituido por estas cinco imágenes. Por integridad académica:

- no se crea una fotografía inexistente;
- no se duplica una imagen para incrementar artificialmente el conteo;
- no se reconstruyen metadatos;
- no se modifica la fecha de una evidencia para aparentar otro registro;
- no se confunde una captura del formulario con una fotografía de aplicación.

La trazabilidad técnica de estas cinco fotografías se encuentra documentada en:

- `../../10_Autoria/README_A11_EXIF.md`
- `../../10_Autoria/exif_inventario.csv`

La existencia de cinco fotografías de aplicación es, por tanto, una característica del conjunto documental real disponible y no una estimación derivada del número de respuestas.
