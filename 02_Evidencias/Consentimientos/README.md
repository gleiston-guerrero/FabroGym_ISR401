# Consentimientos públicos censurados

Esta es la **ruta canónica** de las copias públicas censuradas de consentimiento asociadas a las sesiones del proyecto.

Inventario verificable:

- 10 entrevistas: `ENTR-01..10`
- 3 walkthroughs técnicos: `WALK-TEC-01..03`
- 3 walkthroughs no técnicos: `WALK_NTEC_01..03`

**Total: 16 consentimientos individuales de sesión.**

La guía de cierre menciona 17 consentimientos, pero el expediente reproducible de las 16 sesiones contiene estos 16 formularios específicos. No se fabrica, duplica ni reclasifica un documento para forzar un conteo distinto.

Por compatibilidad con el comando literal de verificación de la guía, existe un espejo byte-idéntico en `08_Etica/consentimientos/`. Ese espejo no constituye evidencia adicional y no debe contarse dos veces.
